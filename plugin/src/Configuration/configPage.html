Mediathek

Die Mediathek erscheint unter „Kanäle“ als „Mediathek“, mit den Reihen ihrer Startseite und einer Suche. Geänderte Einstellungen wirken, sobald Jellyfin den Ordner das nächste Mal lädt.

Wiedergabe

Für Ländersperren zählt dann der Standort des Servers, nicht der des Geräts, auf dem geschaut wird. Abgeschaltet holt jedes Gerät die Videos direkt beim Sender; das spart dem Server die Bandbreite.

Suche

Jeder Begriff erscheint als Ordner unter „Mediathek → Suche“. Die Suche trägt neue Begriffe selbst ein; hier lassen sie sich aufräumen.

Live-TV

Ersetzt die Ordnerliste des Kanals „Mediathek“. Abgeschaltet zeigt Jellyfin den Kanal wie jeden anderen. Mit dem Theme „Cinema Glass“ bleibt die Seite von selbst untätig; das Theme bringt sie in seinem Stil mit.
Die Fassungen zeigen bis auf die Regionalnachrichten dasselbe. Abgeschaltet steht je Sender eine Fassung in der Liste.

Die Live-Programme laufen über das Live-TV von Jellyfin. Der Knopf trägt Senderliste und Programmübersicht dort ein; danach erscheinen die Sender unter „Live-TV“.

Empfang

Manche Sender lassen sich nur aus ihrem Sendeland abrufen. Was dieser Server sicher nicht empfängt (der Sender lehnt den Abruf zweimal ausdrücklich ab), erscheint im Live-TV gar nicht erst. Die Prüfung fragt jeden Sender von diesem Server aus ab und nennt den Grund.
